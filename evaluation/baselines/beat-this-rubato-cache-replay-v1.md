# RUBATO scoped historical-cache replay

## Result

The 25 already-opened RUBATO calibration recordings passed **25/25 exact
historical replays**: original beat timestamps/confidences, model metadata,
candidate counts, and complete selected-score objects agree with the frozen
v11 report. This reuses 9,273 raw beats and 35,151 real candidate peaks.
Actual full PCM regenerated 650,491 onset points and 35,151 supported harmonic
points, plus activity envelopes. No neural inference or cache write occurred.

This is a reproducibility result, **not 25/25 musical accuracy**. Historical
acceptance remains 1/25, with mean beat F1 0.5212633988. Those are scores of
the retained v1 observations replayed through the current engine, not a fresh
v2 backend run or an accuracy improvement.

The [lock](../parity/rubato-cache-replay-lock-v1.json) pins the ordered suite,
all truth and cache-file hashes, historical report, verified model manifest,
input-equivalence proof, and unchanged backend/engine/estimator/scorer/cache
sources. The [summary](../parity/rubato-cache-replay-v1.json) contains compact
counts and scores only. Dense observation and truth exports remain private.

## Compatibility boundary

The preceding [full-PCM proof](beat-this-rubato-pcm-equivalence-v1.md) established
bit-identical complete inputs for this exact native-22,050-Hz cohort. The
replay additionally verifies model artifacts, recomputes each shipping PCM
hash, and binds the original `upstream-default` v1 key to a frozen entire
cache payload. Existing `ObservationCache` still owns schema/key/decoded-shape
validation. The separate evaluator checks the payload before and after
loading, and rejects raw-event/source/candidate-count differences.

Cached activity, onset, and harmonic vectors must be empty: these features
are regenerated by the real shipping `Engine::observe_pcm`, not copied from
the old report or implemented again in Python. The default engine's full
score must then match exactly. Truth supplies evaluation labels only; it
does not select a musical policy or change the engine's analysis.

This explicit evaluator is **not a production cache fallback**. Both source
v1 and shipping v2 identities remain visible. Missing or changed inputs abort;
there is no inference fallback, relabeling, threshold search, or holdout
access. The report proves reproducible analysis from these retained
observations, not cross-machine neural-runtime determinism. Future source,
model, or input changes require new evidence rather than editing this lock
to make a failing run pass.

## Reproduce and next step

```bash
cargo run --locked --profile evaluation -p rhythm-map-eval \
  --example rubato_cache_replay -- \
  --suite evaluation/suites/rubato-calibration-v1.json \
  --model-dir /data/beat-this-full-v1 \
  --audio-dir /data/rubato-calibration-v1 \
  --observation-cache /data/observation-cache \
  --baseline /data/reports/rubato-beat-this-calibration-v11.json \
  --output /data/reports/rubato-cache-replay-new.json \
  --private-evidence /data/parity/rubato-cache-replay-new.private.json
```

Both destinations must be new; private evidence is rejected inside a Git
worktree. Buffered output and explicit flush errors prevent tiny JSON writes
from dominating diagnostic export on slow disks. No PCM is exported.

prove equivalence to the frozen linear lookup (especially equal-distance
