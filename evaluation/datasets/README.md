# Public evaluation datasets

Public audio is managed as immutable external data, not vendored source code.
Each JSON lock records the upstream page, license, attribution, direct HTTPS
URLs, exact byte sizes, and SHA-256 identities. `dataset-fetch` installs only
verified bytes below an explicit output directory and never follows symbolic
links.

## ARTBeaT rhythm challenges v1

[`artbeat-v1.json`](artbeat-v1.json) selects 15 short MP3 exercises and their
official Ground Truth SVGs from the
[ARTBeaT Dataset](https://audiolabs-erlangen.de/resources/MIR/2024-ARTBeaT):
tempo steps, continuous ramps, piano rubato, and polyrhythm. ARTBeaT is
distributed from an AudioLabs download page rather than an official Git
repository, so a Git submodule would not identify the upstream data.

The selected artifacts are licensed CC BY 4.0. Required attribution:

> ARTBeaT Dataset by Rico Rosenbusch, FAU, 2024

The audio and SVG bytes are not committed here. Fetch them outside the checkout:

```bash
cargo xtask dataset-fetch \
  --manifest evaluation/datasets/artbeat-v1.json \
  --output D:/rhythm-map-eval/artbeat-v1 \
  --with-annotations
```

Run the deterministic oracle and end-to-end paths against the same suite:

```bash
cargo xtask eval \
  --suite evaluation/suites/artbeat-v1.json \
  --no-fail

cargo xtask eval-backend \
  --suite evaluation/suites/artbeat-v1.json \
  --model-pack models/beat-this-full-v1.json \
  --model-dir D:/rhythm-map-models/beat-this-full-v1 \
  --audio-dir D:/rhythm-map-eval/artbeat-v1 \
  --no-fail
```

Checked-in beat truth was recovered from the vertical `Ground Truth` lines in
each locked official SVG by mapping its labeled time axis back to seconds. The
truth was not generated by Beat This predictions. Step and ramp tempo truth is
defined from the exercise specification and official beat intervals; ARTBeaT
does not provide downbeat labels, so this suite does not gate downbeat F1.

ARTBeaT is not among the 16 datasets named by the published
[Beat This training-data release](https://zenodo.org/records/13922116). This
makes the locked slice useful as independent public evaluation data; it does
not by itself prove that no unpublished model development ever used the same
audio.
